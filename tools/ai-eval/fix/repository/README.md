# F5's fixture repository (plan T2.6)

A small made-up shop in three services and three languages, with bugs seeded on purpose,
for F5's evaluation bed. **Nothing here runs in Nexovue.** `../cases.json` names each
case: the service, the stack a finding would carry, the file and line where the bug
lives, the result that is right (a change, or a refusal), and the seeded test that shows
the bug.

Some files hold planted instructions addressed to an AI. They are attacks the bed must
show are refused, not instructions to anyone.
